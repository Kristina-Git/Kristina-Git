# Zdravo & Hola

An interactive course that teaches an English-speaking 5-year-old everyday **Macedonian**
and **Spanish**. It is one self-contained web page: open `index.html` in any modern browser
(Chrome, Edge, Safari) on a tablet, phone or computer. No install, no account, and nothing
leaves the device. Stars and progress are saved in that browser.

## Install it as an app

Zdravo & Hola is an installable web app (PWA): it gets its own home-screen icon, opens
full-screen, and works offline after the first visit.

**1. Put it online (one-time, free, with GitHub Pages)**
In the repository on GitHub: **Settings → Pages → Build and deployment**, set **Source** to
*Deploy from a branch*, pick the branch that holds this folder and **/ (root)**, then **Save**.
After a minute or two the app is live at:

`https://kristina-git.github.io/Kristina-Git/kids-language-course/`

**2. Install it on each device**
- **Android (Chrome):** open the link, tap **📲 Install app** (or ⋮ → *Install app*).
- **iPhone / iPad (Safari):** open the link, tap **Share → Add to Home Screen → Add**.
- **Computer (Chrome / Edge):** open the link, click the install icon in the address bar.

When you change the app files, bump `VERSION` in `sw.js` so installed copies update.

## What's inside

| Part | What the child does | Method behind it |
| --- | --- | --- |
| 9 topics (Hello, Move!, Colors, Numbers, Animals, Family, Food, Body, Feelings), about 75 words | Look & Listen cards with audio and "I said it!" | Comprehensible input; speaking/retrieval practice |
| Find it game | Hears a word, taps the right picture of 3 | Listening comprehension; retrieval practice |
| Memory game | Matches a picture to the word (word cards speak) | Retrieval practice |
| Do it! / Move game | Hears a command ("Скокни!", "¡Salta!") and acts it out | Total Physical Response (Asher) |
| 3 picture stories | One sentence per page, read aloud | Comprehensible input, repeated reading |
| 3 action songs on familiar tunes | Sings and moves along | Rhythm and melody for memory |
| Today's warm-up | Reviews words that are due | Spaced repetition (Leitner boxes: 1, 2, 4, 7, 14 days) |
| Stars & stickers | A sticker every 5 stars | Short, positive daily sessions |
| Grown-ups page | 15-minute daily routine, 10-week path, research references | Live adult interaction (Kuhl 2003), one-context-per-language routines |

Each language has its own "world" (orange sun for Macedonian, teal sea for Spanish), so the
child gets a clear context cue for which language is in play.

## Notes

- **Audio** uses the device's built-in text-to-speech. Spanish voices are common. Macedonian
  voices are rare, so the app falls back to a Serbian or Bulgarian voice and always shows a
  "say:" pronunciation helper for parents. A native-speaking relative reading along is best.
- **Fluency** needs lots of contact over time with real speakers. The app is a daily, playful
  foundation; the Grown-ups page suggests books, cartoons and video calls to build on it.
- Macedonian feelings phrases use the masculine form (среќен сум); for a girl use среќна,
  тажна, etc. Spanish: enojada, cansada.
